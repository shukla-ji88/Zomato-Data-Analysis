# Zomato Data Analysis Using Python

## Project Overview
This project analyzes Zomato restaurant data using Python to understand restaurant categories, online ordering trends, customer ratings, restaurant costs, and customer engagement through votes.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key Analysis
1. Restaurant category distribution
2. Online vs offline ordering analysis
3. Average restaurant ratings comparison
4. Approximate cost for two people
5. Total votes by restaurant category
6. Restaurant type vs online ordering heatmap

## Key Findings
- Dining is the most common restaurant category in the analyzed dataset.
- Restaurants that do not accept online orders are more numerous overall in this dataset.
- Online-order restaurants have a higher average rating in this dataset.
- ₹200 is the most common cost value observed in the cost chart.
- Dining has the highest total votes among the restaurant categories.
- Within Dining, online-order restaurants are more numerous than offline-order restaurants.

## Files
- `zomato_analysis.ipynb` — analysis notebook
- `Zomato-data-.csv` — source dataset
- `Zomato_Analysis_Report.csv` — summary report

## Conclusion
The project demonstrates exploratory data analysis, data cleaning, aggregation, and visualization using Python. The findings describe this dataset and should not be interpreted as representing every restaurant on the Zomato platform.
